# Imagens dos grupos (círculos do acervo na página inicial)

Coloque aqui uma imagem por grupo, com o nome exato abaixo (minúsculas, `.jpg`).
O site aplica a imagem como fundo clareado do círculo; grupos sem imagem continuam brancos.
Não precisa mexer no código: é só adicionar o arquivo, commitar e dar push.

Dica: imagens quadradas, de ~400×400 px e até ~100 KB, carregam rápido.
